# 基翔學務雲

基翔文理補習班的統一入口：一個帳號登入，依身分進入各系統。

網址：https://mcdull60555.github.io/jixiang-educloud/

| 身分 | 可以進入 |
|---|---|
| 管理員（admin） | 雲點名、學習通、學生名冊、學費管理、帳號管理 |
| 老師 | 雲點名、學習通 |
| 學生・家長 | 學習通、學費單 |

- 學生、家長：輸入學生帳號（JX＋國小一年級入學學年＋流水號，例如 JX115001）與 4 位數密碼。
- 老師、管理員：從下拉選單選帳號，再輸入密碼。
- 在入口登入後，於同一個分頁點進雲點名或學習通不需要再登入。
